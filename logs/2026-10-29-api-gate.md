## Затверджено людиною на API-GATE

- Уточнення агента з розділу 6 `docs/api/resources.md` (крім №3, зміненого людиною) і правила
  протоколу РА-13: 415 для тіла не в JSON, 422 для невідомих полів і полів лише для читання,
  сторінка за межами — 200 з порожнім `items`, фільтр стрічки з неіснуючим ідентифікатором — 200 з
  порожнім списком, повторний `PUT …/link` з тим самим матеріалом — 200 без змін, ручний запуск без
  активних постачальників — 200 із записом журналу.
- Тексти `title` і `detail` у моделі помилок (ПА-9); дослівні тексти SRS не змінено.
- Без змін: РА-06 (405 описано в `info.description`, бо OpenAPI не описує відсутніх методів),
  відсутність `GET` для прив'язки (РА-10).

## Відомі обмеження mock

- Prism віддає шляхи без префікса `/api/v1`; для сервера в Лаб. 5 базова адреса
  `http://localhost:8000/api/v1`.
- 404 і 405 на невідомий шлях чи метод Prism віддає у власному форматі, тому для Н-07 і Н-08 проти
  mock перевіряється лише статус.
- Prism не відповідає на тіло, що не є JSON (Н-27).
