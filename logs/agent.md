# Кодинговий агент проєкту

**Інструмент:** Claude Code (Anthropic).
**Клас:** кодинговий агент у терміналі (CLI-агент на основі великої мовної моделі).
**Спосіб доступу до репозиторію:** працює безпосередньо з файлами локального клону репозиторію
на робочій машині; віддаленого доступу до GitHub не має.
**Операції в робочому середовищі:**
- читання та аналіз структури проєкту і вмісту файлів;
- створення та редагування файлів;
- запуск команд у терміналі (git status / diff / add, тести, лінтер).

**Обмеження за правилами проєкту (CLAUDE.md):** агент не робить комітів — лише готує зміни
до індексу (`git add`), після чого людина переглядає `git diff` і комітить сама.
Кожна сесія фіксується окремим записом у `/logs/`.
